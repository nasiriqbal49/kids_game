# Universal Motion Controller Specification

## 1. Operating Modes
1. **Hub Mode:** Menu launcher to pick top games (Poki, CrazyGames, Temple Run 2, Subway Surfers) or enter the Interactive Academy.
2. **Mini-Dock Mode:** Lightweight floating preview showing live webcam skeleton, last detected action, and controller status.
3. **Background Mode:** Controller operates silently while any PC game, emulator, or custom web URL is open in the foreground.

## 2. Sandboxing & Safety
- Web portals launch in borderless App/Kiosk Mode (`--app=URL`) via Chrome or Edge to isolate kids from the Windows desktop and personal folders.
- Seated Couch Mode: Allows driving with a paper plate or shooting with toy guns from 4 to 6 ft away without requiring floor zone calibration.

## 3. Air Mouse Specification (Planned)
- Raising an open palm maps wrist/index coordinates to the screen cursor.
- Quick forward index thrust or thumb pinch triggers Left Mouse Click to restart runs or pick levels hands-free.
